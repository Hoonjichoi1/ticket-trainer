- [ ] 진행 중

## 개요

Task 004의 디자인 시스템·공통 컴포넌트·더미 데이터를 사용해 홈→대기열→좌석→예매정보→결제→결과 전 페이지를 실제 사용 가능한 화면으로 완성한다. 백엔드 API는 아직 없으므로 모든 상태는 더미 데이터와 로컬(클라이언트) 상태로만 구성하며, Phase 3에서 페이지별로 실 API로 교체될 자리를 명확히 남긴다. 관련 기능: F001, F002, F003, F004, F005, F011, F013, F014.

작업량이 많아 아래 8개 서브태스크로 분할해 진행한다. 각 서브태스크 파일이 상세 수락 기준/구현 단계를 갖는다.

좌석 선택은 전체 200석을 한 번에 보여주지 않고, 구역 선택 → 좌석 선택 2단계로 진행한다. 실제 대형 아이돌 콘서트장(KSPO돔류 원형 다층 아레나)의 구조감을 참고하되, 특정 공연장 도면을 그대로 재현하지 않고 자체 스타일로 구현한다. 구역은 무대를 기준으로 **좌우**로 나뉘므로, `Seat.number`(좌석 번호)를 기준으로 그룹핑한다 — `Seat.row`(무대와의 거리, 앞/뒤)는 구역 구분에 사용하지 않는다.
