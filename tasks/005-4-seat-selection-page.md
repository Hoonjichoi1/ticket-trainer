## 개요

Task 005 분할 중 가장 복잡한 서브태스크. 전체 200석을 한 번에 보여주지 않고, 구역 선택 → 좌석 선택 2단계로 진행한다. 실제 대형 아이돌 콘서트장(KSPO돔류 원형 다층 아레나)의 구조감을 참고하되 특정 공연장 도면을 그대로 재현하지 않고 자체 스타일로 구현한다. 관련 기능: F005.

- [ ] 구역은 무대와의 거리감이 느껴지도록 시각적으로 배치됨 (원형/부채꼴 느낌, CSS transform 활용, 실제 좌표 계산 없이 구현)

1. [ ] Task 005-1의 구역 그룹핑 헬퍼로 200석을 5구역으로 분류
2. [ ] 구역 미리보기 컴포넌트 구현 (블록 5개, 무대 위치 표시, 클릭 가능, 원형/부채꼴 CSS transform 배치)
3. [ ] 구역 클릭 시 좌석맵 뷰로 전환하는 로컬 상태(단계 전환) 구현
